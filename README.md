# Mass Server Leaver

A BetterDiscord plugin designed to clean up your workspace by letting you leave multiple Discord servers in bulk.

</div>

---

## Overview

Have you ever logged into Discord only to find your server list cluttered with dozens of inactive servers that ruin your layout? **Mass Server Leaver** solves this by providing a streamlined interface to select and leave multiple servers all at once, saving you from manual, one-by-one removal.

## Features

* **Bulk Selection:** Select multiple servers simultaneously rather than going through context menus individually.
* **Streamlined UI:** Integrates smoothly into the BetterDiscord ecosystem.
* **Lightweight:** Built cleanly using JavaScript for optimal performance inside the Discord client.

---

## Installation

1. Download the latest release of `MassServerLeaver.plugin.js`.
2. Move the file into your BetterDiscord plugins folder:
   * **Windows:** `%appdata%\BetterDiscord\plugins`
   * **Mac/Linux:** Check your BetterDiscord settings panel for the plugin directory.
3. Enable the plugin from your Discord settings under **BetterDiscord -> Plugins**.
4. Next just hold "ctrl" key and click on the servers you want.
5. Click Process Selected.
6. Then done.
